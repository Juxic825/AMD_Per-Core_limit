# AMD频率限制器
使用方法
1.先安装依赖；

2.左上角的框限制cppc，进而限制频率，点击应用生效（不生效的重启一下电脑）；

3.【PerfMax】里的范围是所选定核心的范围，输入（A/a）应用或者直接点【恢复默认】是设定到每个核心的最大值；

4.逐核限制可以用滚轮，步进是3；

5.【开机自启】在【设置】里，开了就自动运行且生效，【静默自启】是不弹窗口；

6.核心频率有效频率那里，抓的是windows自带的频率接口和有效，频率和HWinfo里的不同，不接入HWinfo是因为太吃性能，打游戏烧心；

7.【禁用闲置】是为了能观测到闲置的频率，尽可能的接近实际频率，用完记得关；

8.你们就拿去用吧，不是啥高深、值钱玩意，别骗钱祸害人就行；

9*.用这个软件记得Bios里的pss不能关，3d v-cache不能装。微星主板没关驱动安装的话会自动下3d v-cache，装有的去服务里自己禁用；
